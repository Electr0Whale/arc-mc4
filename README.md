## 中文说明

本项目为 Minecraft 模组整合包 **Better MC 4 (BMC4)** 的工程历史备份与专用客户端归档镜像。

### 资源下载与解压说明

大体积压缩包统一存储于本仓库的 **[GitHub Releases](https://github.com/Electr0Whale/arc-mc4/releases)** 资产页面中：
- **工程完整备份分卷**：`BMC4.7z.001` 至 `BMC4.7z.004`（需全部下载至同一文件夹后再解压）；
- **客户端专用包**：`client_backup` Release 中的 `BMC4.client.7z`。

### 解压密码说明

根目录下的 `backup.pswd` 记录了压缩包解压所需之独立密钥。为防范抓取，密钥未直接展示在说明正文中；克隆或拉取仓库后，查看该文件即可获得解压密码。

### 声明与权属

本仓库仅作为个人工程与游玩档案的历史归档，不代表 Better MC 官方主干。Minecraft、Better MC 及其中所集成的所有开源/闭源模组版权归 Mojang Studios 及各模组原作者所有。

## English

Preservation archive of a historical Better MC 4 (BMC4) project instance and its associated client distribution.

### Downloads
Large archive blobs are available under **[GitHub Releases](https://github.com/Electr0Whale/arc-mc4/releases)**:
- Split project backup files: `BMC4.7z.001` through `BMC4.7z.004`
- Dedicated client package: `BMC4.client.7z`

### Extraction Password
Refer to the local file `backup.pswd` in the repository root for the archive password.

### Disclaimer
Maintained purely for archival backup purposes. All rights to Minecraft, Better MC, and included mods belong to their respective creators.

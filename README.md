# Better MC 4 Archive

Archive of a Better MC 4 project backup and its client package.

## Downloads

Large files are stored as GitHub Release assets:

- the dated project backup is split across `BMC4.7z.001` through `BMC4.7z.004`;
- the `client_backup` Release contains `BMC4.client.7z`.

Download every numbered part of a split archive into the same directory before extracting the first part.

## Archive password

`backup.pswd` contains the extraction password used by the archived packages. The password is intentionally not duplicated in this README; read the file locally when restoring the archive.

## Status

This repository is a preservation backup rather than the upstream Better MC 4 project. It does not claim ownership of Better MC, Minecraft, included mods, or third-party assets. Refer to the licenses and distribution terms supplied by the original project and individual mod authors.
